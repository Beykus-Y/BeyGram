# Переключение камеры во время записи кружка

Статус: реализовано. Ветка `claude/project-thread-ycfx5a` от DEV (1a80a85). Флаг `VIDEO_NOTE_RECORDING_ENABLED` остаётся выключенным: его включит задача круговой маски (PR #64).

## Как работает

- `VideoNoteRecorder` создаёт `Recorder` и `VideoCapture` один раз на запись (`createCapture`); каждая запись начинается с фронтальной камеры, а если её нет, с основной.
- Запись стартует как persistent (`asPersistentRecording()`), поэтому не обрывается при перепривязке `VideoCapture`. Если устройство не умеет persistent-запись, старт повторяется без неё, а переключение камеры скрывается до конца сессии рекордера: `videoSwitchCameraAvailable` учитывает `persistentSupported`, поэтому следующие записи кнопку не возвращают.
- Переключение во время записи: `unbindAll()`, затем `bindToLifecycle` с тем же capture и новым селектором. `Preview` пересоздаётся, `VideoCapture` — нет. Проверки доступности камеры и FPS выполняются до `unbindAll()`: если сбоила только проверка, запись продолжается без изменений.
- Перед перепривязкой диапазон FPS, зашитый в capture, сверяется с поддерживаемыми диапазонами целевой камеры; без совместимости переключение отклоняется с сообщением — пересоздать capture без обрыва записи нельзя.
- Если перепривязка упала, камера возвращается прежней, запись продолжается, пользователь видит сообщение `recorder_camera_switch_failed`. Если и возврат упал (двойной сбой), сессия аварийно завершается: discard + `stop()`, пользователь видит `recorder_camera_switch_aborted` — Recording без привязанной камеры и зависший интерфейс недопустимы.
- `Finalize` с ошибкой (`event.error != 0`) и внеплановый `Finalize` без `stop()` гасят состояние записи; частичный файл не отправляется. Отправка разрешена только после явного `requestStop()` — политика `videoTakeOutcome`, покрыта юнит-тестами.
- Кнопка переключения живёт в `VideoNoteRecordingOverlay` (правый нижний край квадрата, вне контейнера с `clip(CircleShape)`): видна с открытия экрана записи, нажимается после события `Start`. Кнопка до записи из композера удалена.
- Без второй камеры (`canSwitchCamera` ложь) кнопка скрыта.
- Зеркало превью только у фронтальной камеры: `PreviewView` отражает её сам, ручной `scaleX` не нужен (см. PR #61).

## Открыто

- Длительность и видимость паузы кадра при перепривязке не измерены.
- Звук при перепривязке не проверен.
- Всё проверяется только на физическом устройстве после включения флага. Сборка идёт только в CI.
