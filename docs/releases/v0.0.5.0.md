# BeyGram 0.0.5.0

## Что нового
- Стили интерфейса: пять вариантов в разделе «Оформление» → «Стиль интерфейса» — Стандартный BeyGram, Liquid Glass, BeyGram Signature, Material 3 и Material 2. Нижняя панель навигации может стоять отдельно для каждого стиля.
- Liquid Glass: стеклянная шапка списка чатов, плавающие панели с размытием фона и тонкий контур вокруг каждого слоя.
- Память чата (выключена по умолчанию, включается в настройках): сохраняет сообщения, которые удалили в чате (свои не сохраняются), и прежние версии изменённых сообщений. Прежние версии открываются из пузыря, а в настройках «Память чата» есть лимит, очистка и выбор чатов.
- Слова-триггеры: уведомление, когда в сообщениях появляется заданное слово. Поиск не зависит от языка, есть отдельная лента упоминаний и очистка.
- Режим невидимки: сообщения уходят через отложенную отправку Telegram, для отдельных чатов можно сделать исключения, а перед действиями, которые могут показать активность, приложение предупреждает.
- Отложенная отправка: задержка на выбор 1, 3, 5, 10, 30 или 60 секунд, список отложенных сообщений открывается из меню чата в нижней панели.
- Музыка: «Моя музыка» с локальной библиотекой и плейлистами, «Добавить в плейлист» из плеера, карточки плейлистов .bgmusic в чатах с импортом и экспортом.
- Музыка в профиле: трек профиля показывается под аватаром в своём и чужом профиле и играет через общий плеер. Трек из чата можно добавить в свой профиль из плеера, а в своём профиле треки можно переставить первым или удалить.
- Переходы между треками: пропуск тишины между треками (включён по умолчанию) и плавный переход на 4 секунды (выключен по умолчанию). Цвет плеера берётся из обложки трека.
- Поиск музыки доступен прямо из списка чатов и из плеера.
- Композер: горизонтальная лента фото и видео с перестановкой, смешанные вложения, подпись рядом с полем ввода, реакции внутри пузырей и спойлеры.
- Контакты: алфавитные разделы и поиск по номеру, если у контакта показан username.

## Улучшения
- Навигация: кнопка «Назад» возвращает на нужный экран после нескольких переходов, переходы между экранами стали плавнее.
- Список чатов обновляется только там, где пришли изменения; анимации и GIF запускаются, когда объект виден дольше 500 мс.
- Шапка списка чатов сжимается при прокрутке, настройки отдельного чата открываются в нижней панели, а переключатели в настройках чата выглядят одинаково.
- Поле поиска использует одно действие «Поиск» на клавиатуре и растёт при крупном шрифте.
- Счётчики в архиве читаются с разделителями разрядов, бейджи непрочитанных остаются читаемыми при крупном шрифте.
- Звонки, контакты, профиль и настройки оформлены в выбранном стиле интерфейса.
- Мини-плеер в чате стоит под шапкой и не перекрывает клавиатуру.
- Обои чата выбираются из ленты с предпросмотром вместо текстового списка.
- Оформление: панель «Применить» появляется только при несохранённых изменениях, с кнопкой «Отмена».
- В контактах не повторяются значки «⋮», действия доступны долгим нажатием.
- Истории: нажатие подсвечивается кругом, а непрочитанная обводка стала мягче.
- Время у коротких сообщений выводится компактнее.

## Исправления
- Выход из аккаунта очищает таймеры памяти чата и уведомления триггеров; настройки чатов не переходят между аккаунтами.
- Поиск музыки не показывает устаревшие результаты, а возврат из очереди к плееру стал явным.
- Плеер центрирует содержимое, если для него есть место, а лист плеера не дёргается в конце списка.
- Свайпнутая строка чата возвращается на место только после ответа Telegram.
- Адаптивные кнопки профиля и смены фото не перекрывают друг друга.
- Индикатор набора текста не перекрывает панель вложений.
- Музыка: медленная загрузка не обрывает воспроизведение, а скачанные треки сохраняются целыми.
- Счётчик непрочитанных у кнопки «К последним» не обрезается.
