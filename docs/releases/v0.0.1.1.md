# BeyGram 0.0.1.1

## Улучшения
- BeyGram появился в системном меню «Поделиться» для текста: выберите чат, при необходимости поправьте текст и нажмите «Отправить». Без вашего нажатия ничего не уходит. Фото, файлы и темы форумов пока не поддерживаются.
- Заметки «Что изменилось» в окне обновления показываются с форматированием: заголовки, списки с номерами и переносы строк внутри пункта.
- В заметках обновления больше не показывается технический раздел для разработчиков.
