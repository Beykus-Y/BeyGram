# BeyGram 0.0.1.1

## Улучшения
- BeyGram появился в системном меню «Поделиться»: текст, фото, видео, аудио и файлы можно отправить в выбранный чат. Перед отправкой видно, что уйдёт, и её нужно подтвердить. Темы форумов пока не поддерживаются.
- Заметки «Что изменилось» в окне обновления показываются с форматированием: заголовки, списки с номерами и переносы строк внутри пункта.
- В заметках обновления больше не показывается технический раздел для разработчиков.
