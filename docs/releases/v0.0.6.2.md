# BeyGram 0.0.6.2

Исправление входа в аккаунт.

## Исправления
- Кнопка «Получить код» больше не крутит бесконечную загрузку сразу после перехода на экран номера телефона.
- Вход по номеру после переключения с QR-кода работает: приложение сначала завершает QR-вход, а затем отправляет номер.
- Если соединение долго не отвечает, экран входа больше не зависает: появляется сообщение о проблеме с соединением и кнопка переподключения, после которой форму можно отправить снова.
- Поздний ответ на старую попытку входа больше не показывает ошибку поверх новой попытки.
- Ошибка отмены загрузки файла больше не влияет на состояние входа.

## Диагностика
- В отчёт о проблеме попадают код ошибки и этап входа, без номера телефона, кода, пароля и QR-ссылки.
