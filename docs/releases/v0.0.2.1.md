# BeyGram 0.0.2.1

## Что нового
- При записи видеокружков появилась подсветка: для камеры со вспышкой доступен непрерывный свет, а для фронтальной камеры без вспышки — экранная подсветка. При завершении записи, отмене и сворачивании подсветка выключается.
- В системном меню Android «Поделиться» BeyGram предлагает недавние чаты. Перед отправкой открывается экран проверки: сообщение не отправляется автоматически.
- В чате появились полноценные карточки музыкальных файлов с управлением воспроизведением, названием трека и обложкой, если она доступна.
- В оформлении чатов узорные обои удобнее листать по горизонтали; добавлена настройка размера текста сообщений с живым предпросмотром.

## Улучшения
- Список тем форума показывает доступные темы по мере загрузки и не блокирует весь экран долгим ожиданием. Закреплённые, закрытые и непрочитанные темы выделяются понятнее.
- Предпросмотр оформления показывает ответы, медиа и служебные сообщения. Цвета системных элементов Material 3 согласованы с выбранной темой и улучшен контраст элементов.
- Экран отправки файлов и диагностических отчётов предлагает «Избранное» и недавние доступные чаты, при этом сохраняется отдельное подтверждение отправки.
- Видеокружки используют более точную проверку возможностей камеры и видеокодировщика при выборе частоты кадров; при поддержке устройства возможен переход на подходящий SD-режим без искусственного увеличения разрешения.
- Диагностика видеокружков подробнее объясняет ограничения FPS и помогает сравнивать угол обзора, исходный поток и итоговое видео.
- При смене языка через системные настройки Android экран выбора языка BeyGram показывает актуальный выбор; улучшено управление с помощью специальных возможностей.

## Исправления
- Звонки больше не отображаются пустыми сообщениями: история чата показывает направление, статус и длительность звонка, когда эти данные доступны.
- Исправлены потеря обложки и отдельные проблемы воспроизведения музыки при переходах между экранами.
- Сохранение безымянных вложений с неизвестным MIME точнее определяет распространённые форматы по короткой сигнатуре файла, не меняя его содержимое и не подменяя исходные имена.
- При задержках ответа Telegram экран «Устройства и сеансы» не остаётся в бесконечной загрузке, а предлагает повторить запрос. Если завершение сеанса не подтверждено, приложение предупреждает о неопределённом результате.
- Если восстановление встроенного прокси Mihomo зависло, попытка ожидания ограничена по времени и пользователь снова получает возможность выбрать действие.
- Улучшено поведение видеокружков при первоначальном масштабе камеры, переключении объективов и выборе совместимого профиля записи.

## Известные проблемы
- Реальные 60 FPS зависят от камеры, освещения и кодировщика; программные настройки не могут обеспечить 60 FPS на устройстве, которое поддерживает только 30 FPS.
