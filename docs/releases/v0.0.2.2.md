# BeyGram 0.0.2.2

## Что нового
- В оформлении чата можно выбрать цвет текста сообщений и цвет времени в сообщениях.
- В оформлении можно настроить скругление пузырей сообщений и межстрочный интервал: плотный, обычный или свободный.
- Фото на обоях чата можно размыть. Эффект работает на Android 12 и новее; на старых версиях фото затемняется сильнее.
- В редакторе темы появилась отмена последнего изменения, чтобы быстро вернуть предыдущий вариант.

## Улучшения
- Добавлена автоматически включённая статистика установок: версия клиента, Android, модель устройства, активность, число аккаунтов и Telegram ID для проверки статуса официального бета-тестера. Отключить и удалить запись можно в настройках диагностики.
- Кнопка «Создать группу» закреплена над списком контактов и остаётся видна при прокрутке. Не нужно листать до конца списка, чтобы создать группу.
- Граница с датой на обоях чата стала аккуратнее.

## Исправления
- Выбор обновления в канале DEV теперь находит самую новую тестовую сборку, даже если GitHub показывает сборки не по порядку.
