# Проверка «Поделиться» на устройствах

Чек-лист для ручной проверки отправки из других приложений в BeyGram. Проверять на dev-сборке, на аккаунте, которым не жалко рисковать.

## Подготовка
- Установить сборку поверх существующей через `adb install -r` (не удалять приложение и не очищать данные).
- Убедиться, что вход в аккаунт сохранился.

## Android 10 и Android 13 / 16
- [ ] Текст из браузера (выделенный фрагмент) → «Поделиться» → BeyGram → выбрать чат → текст в поле, отправка.
- [ ] Ссылка из браузера → то же самое, ссылка уходит целиком.
- [ ] Одно фото из Галереи → предпросмотр с именем файла, подпись, отправка.
- [ ] Несколько фото (2–10) → отправляются одним альбомом.
- [ ] Видео из Галереи → отправка как видео.
- [ ] Файл из приложения «Файлы» (PDF, архив) → отправка как документ.
- [ ] Аудиофайл из «Файлов» → отправка как документ (это ожидаемо).
- [ ] Больше 10 файлов → показано сообщение о лимите, лишние не добавляются.

## Выбор чата и темы
- [ ] Поиск по названию чата находит нужный чат, в том числе из архива.
- [ ] Обычный чат → сразу предпросмотр, без выбора темы.
- [ ] Группа с темами → появляется список тем; без выбора темы отправки нет.
- [ ] Выбранная тема: сообщение появилось именно в ней, а не в General.
- [ ] Группа с темами без тем → показано «В этом чате пока нет тем», кнопки отправки нет.
- [ ] Кнопка «Назад» возвращает от темы к списку чатов.
- [ ] Ошибка загрузки тем показывается, отправка не происходит.

## Черновик и текст
- [ ] В чате был черновик → после отправки из «Поделиться» черновик сохранился.
- [ ] Текст длиннее 4096 символов → показано сообщение, кнопка «Отправить» неактивна.
- [ ] С файлом подпись длиннее лимита Telegram → кнопка неактивна, подпись сокращается вручную.
- [ ] Эмодзи в тексте считаются верно (длина не завышена).

## Надёжность
- [ ] Поворот экрана во время отправки: сообщение уходит один раз, дубля нет.
- [ ] Поворот экрана до отправки: выбранный чат, тема и текст сохраняются.
- [ ] Во время отправки системная «Назад» не закрывает экран.
- [ ] Выход из приложения во время подготовки файлов (свернуть и убить процесс): после повторного «Поделиться» можно отправить файлы заново; старые копии не копятся в памяти (проверить в файлах приложения).
- [ ] Нет сети: показано сообщение об ошибке, текст не теряется, можно повторить.
- [ ] Отмена на экране выбора чата закрывает шторку, ничего не отправляется.

## Экран и доступность
- [ ] Клавиатура не перекрывает поле ввода подписи и кнопку «Отправить».
- [ ] Поворот экрана в альбомную ориентацию: элементы доступны прокруткой.
- [ ] TalkBack читает названия чатов, тем, кнопки и сообщения об ошибках.
- [ ] Шрифт системы увеличен до крупного: строки не обрезаются непонятно.

## Сборки
- [ ] Dev и Prod установлены одновременно: в меню «Поделиться» видны обе, каждая открывает свой аккаунт.
- [ ] Shortcut или уведомление не ломают поведение «Поделиться».

## Что записать при сбое
- Версия Android, модель устройства, сборка (dev/prod), приложение-источник, тип файла и размер.
- Экран до и после действия, текст ошибки, если он показан.
- Отчёт диагностики из Профиль → Уведомления → «Поделиться логами», если он есть.
