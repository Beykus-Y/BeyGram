# BeyGram Forums 2.0 — этап 1

Зонтичная задача: #874. Этот этап закрывает список тем, метаданные и переход в тему; редактор темы и три режима
навигации остаются следующими PR.

## Что вошло

- Плотный список тем в геометрии основного списка чатов: одна строка, стабильные ключи, разделители, секции
  закреплённых и обычных тем, сохранение позиции прокрутки.
- Реальная иконка темы: серверный цвет, custom emoji через существующий `CustomEmojiImage`, отдельный значок General,
  fallback без загрузки файла. Закрепление, закрытие, mute, черновик и непрочитанные упоминания/реакции/опросы — отдельные
  компактные индикаторы, а не замена иконки.
- Метаданные последнего сообщения: автор, время, исходящее/прочитано, media/service-превью по правилам списка чатов.
  Дополнительных запросов истории на каждую строку нет.
- Шапка с аватаром и названием группы, точным числом загруженных тем, участниками на широком экране, поиском и
  созданием темы. General и закрытая тема различаются в шапке переписки; родительская группа вынесена в подпись.
- Поиск по названиям через `GetForumTopics(query)` — включая темы, которых нет в загруженных страницах. Результаты
  приходят первой страницей, пока остальные ещё грузятся. Фильтр «Все / Непрочитанные».
- Управление темой по долгому нажатию: переименование, закрытие/открытие, закрепление, удаление. Удаление General
  запрещено независимо от прав; действия доступны TalkBack через long-click label.
- Строки и состояния на ru/en/de/es/fr; светлая/тёмная тема, все стили оформления, крупный шрифт, две панели.

## Контракт данных

`ConversationRepository.forumTopicsPage` отдаёт **кумулятивные** снимки: каждый `ForumTopicsPage.topics` содержит все
страницы, полученные к этому моменту. `isComplete` истинно только когда сервер не дал следующую страницу и курсор не
повторился. `ForumTopicsPage.totalCount` — приблизительное серверное число (может включать скрытые темы), поэтому
завершённый список показывает фактическое число строк, а не `totalCount`.

`forumTopics` сохранён как обёртка для выбора темы при пересылке/экспорте. `latestForumTopicPreview` удалён: превью
теперь приходит из `forumTopic.lastMessage` без N+1 запросов. Для давно неактивной темы без `lastMessage` показывается
нейтральная подпись.

## Следующие этапы

1. Полноценный редактор темы: имя, цвет, серверная иконка/custom emoji, ошибки без потери ввода, подтверждения #870.
2. Три режима навигации (классический, горизонтальная панель, вертикальная панель) с сохранением выбора на
   `accountId + chatId`, черновиков, истории и позиции каждой темы.
3. Интеграция форумов в основной список чатов: признак форума, последняя активная тема, ограниченный кеш без загрузки
   всех тем на каждый bind.
4. «Все сообщения» форума и перетаскивание закреплённых тем, если это подтверждает установленная версия TDLib.
