## Lifecycle, сохранение и неопределённость

- **Смена аккаунта и restart.** Legacy и secondary имеют отдельные preference-файлы и store. Экран настроек keyed по аккаунту. Для перехода с открытым чатом проверить одинаковый chatId в обоих аккаунтах, незакрытые диалоги согласия, возврат из Recents и RemoteInput для фонового аккаунта.
- **Ошибка сохранения.** Неуспешный commit может принять более строгую конфигурацию до завершения процесса. Менее строгая конфигурация отбрасывается. UI сообщает об ошибке, но после restart может загрузиться предыдущая запись. FailClosed применяется при исключении чтения либо повреждённой записи, если отсутствует явно читаемый флаг «выключено». Пустой store начинает с Normal. В FailClosed четыре действия чата и присутствие ограничены, планирование остаётся действующим.
- **Открытый чат, reconnect и in-flight.** `refreshPolicy` очищает дедупликацию, прекращает неподходящие циклы, пересчитывает online. `visible` перепроверяет policy перед каждой попыткой, однако задержанный retry может пережить выключение и повторное включение разрешения между проверками. Отдельный тест должен воспроизвести этот переход и смену клиента. Уже переданный запрос отозвать нельзя.
- **Отправка.** Scheduler фиксирует решение и handoff под блокировкой store, проверяет серверные часы и ограничения secret/paid/channel DM и неподходящего контента. Часы читаются до handoff. При потере сети после handoff нужен исход «неизвестно» до сверки. Старая задержка 1–14 секунд сохраняется видимой, отправка с ней отклоняется до явного выбора значения 15–3600.
- **Подтверждение для UI.** `stealthWillSchedule` — прогноз. Использующий его toast «Запланировано на сервере» обещает больше имеющихся данных. Этап прозрачности должен сообщать о подтверждении по успешному обновлению TDLib без pending и с scheduling state либо по повторно загруженной серверной очереди. Путь прогноза может показать нейтральное сообщение со ссылкой на очередь. [StealthSendGuard.kt](../app/src/main/java/com/beykus/beygram/ui/screens/chat/StealthSendGuard.kt#L72) · [ChatScreen.kt](../app/src/main/java/com/beykus/beygram/ui/screens/chat/ChatScreen.kt#L655)

## Быстрый доступ и исключения

- Меню аккаунта → текущий режим и компактная панель за два действия. Подходит для глобальной политики. Использовать активный store и закрывать панель при переключении аккаунта.
- Контекст чата → текущее Inherit / Allow / Block; хорошая точка для исключения конкретного чата. Глобальные настройки остаются в маршруте приватности.
- Маршрут настроек → текущий `StealthSettingsScreen`. Использовать его для всех семи переключателей, предупреждений и серверной приватности. Дополнительная постоянная вкладка не требуется.
- На экране исключений использовать только ID из текущего store. Сопоставлять их с именами и типами из текущего аккаунта. Записи, имена которых недоступны, сохранять и позволять сбросить. Inherit удаляет запись. Поиск по имени и фильтры Allow/Block и типу чата влияют на представление, счётчик показывает отфильтрованные и все записи. Сброс всех требует явного подтверждения. Ошибка записи оставляет на экране фактический результат store.

## Проверка с добровольными тестовыми аккаунтами

| Сценарий | Повторяемая проверка |
| --- | --- |
| A → B, одинаковый чат, переключение и restart | Разные режимы и исключения у каждого аккаунта. Проверить основной экран, диалоги, уведомления, возврат к исходному аккаунту |
| Режим меняется во время открытого диалога | Фиксировать вызовы TDLib без содержимого сообщений, наблюдать отметки и typing во втором клиенте. Прервать сеть на handoff и во время retry |
| Серверное планирование и ошибка | Сверить очередь со второго клиента того же тестового аккаунта, закрыть приложение и отключить сеть, дождаться доставки. Проверить отмену и ambiguous timeout без повторной отправки |
| Согласие и ограничения | Отмена и согласие для view-once, обычной отправки, опроса, Wave и reply из уведомления. Проверить secret chat, оплачиваемый чат и live location |
| UI и доступность | TalkBack, шрифт 200%, reduced motion, светлая и тёмная темы, небольшой экран, landscape. Проверять выбор пресета, disabled state, ошибку сохранения и возврат из списка исключений |
